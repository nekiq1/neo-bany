# Баня «Капля» — онлайн-бронирование + админ-панель

React 19 + Vite + PocketBase. Сайт для бани/сауны с бронированием по часам и мобильная админка «Расписание» (`/admin`).
Демо-данные сделаны по образцу бани «Капля» (СПб, Мичманская ул., 4); всё меняется в админке — название, адрес, залы, цены, фото.

## Быстрый старт

```bash
cp .env.example .env.local          # VITE_PB_URL=http://127.0.0.1:8090
npm install

# 1) бэкенд: скачайте PocketBase 0.23+ (https://pocketbase.io/docs/) и запустите из корня проекта
./pocketbase serve --hooksDir=pb_hooks --migrationsDir=pb_migrations
#    миграции сами создадут коллекции и демо-данные

# 2) http://127.0.0.1:8090/_/ → создайте суперпользователя
# 3) там же: коллекция users → New record → email и пароль (логин для /admin)

# 4) сайт
npm run dev                         # http://localhost:5173 · админка: /admin
```

В `/admin` можно войти пользователем из `users` или суперпользователем PocketBase.

## Как это работает для гостя

1. Главная: залы, цены, акции, удобства, фото, адрес и маршрут.
2. «Бронь»: зал → дата → время начала → длительность → гости → допуслуги (веники, полотенца…) → контакты.
3. Недоступное время (уже занято, прошло, вне часов работы, не хватает времени до следующей брони) блокируется само, между бронями учитывается время на уборку.
4. Цена считается на лету. Итоговую сумму **ещё раз считает сервер** по ценам из базы — подделать её с клиента нельзя.
5. Заявка приходит администратору со статусом «Новая». Оплата — на месте.

## Что умеет админка

| Раздел | Что делает |
|---|---|
| Расписание | День / неделя; счётчики «Заезды», «Выполнено», «Получено»; подтвердить, выполнено, оплачено, отменить, вернуть, удалить; новые заявки появляются сами |
| Добавить запись | Ручная бронь (с автосчётом суммы, можно поправить) или блокировка времени одного зала / всех залов |
| Часы работы | Круглосуточно или часы; макс. часов в брони; уборка между бронями; закрытие онлайн-брони за N минут; «счастливые часы» (время и дни недели) |
| Контакты | Название, телефон, адрес, сайт, описание |
| Карточки витрины / Работы | Фото-галерея: загрузка нескольких фото, подписи, кадрирование, порядок |
| Услуги | **Залы**: цена/час, цена в счастливые часы, вместимость, гости в цене, доплата за гостя, минимум часов, фото. **Допуслуги**: веники, полотенца, массаж и т. д. (за шт. / за визит / за час) |
| Логотип, Главное фото | Загрузка, кадрирование, сброс на стандартное |
| Акции | Карточки акций и список удобств на главной |

Всё сохраняется в PocketBase и сразу видно на сайте.

## Расчёт цены

`цена = часы по обычной цене + часы по «счастливой» (если включено и зал её имеет) + (гости − гости в цене) × доплата × часы + допуслуги`.
Время считается в часовом поясе студии (по умолчанию МСК, +180 мин), а не в поясе телефона гостя.
Формулы клиента (`src/lib/pricing.ts`) и сервера (`pb_hooks/pricing.js`) совпадают — это проверено прогоном на сотнях комбинаций.

Ограничение: тарифная модель одна — «обычная цена» и одно окно счастливых часов. Отдельные цены вроде «выходные днём 1600 ₽» не заложены; их можно добавить в `pricing.ts` и `pricing.js`.

## Безопасность

- Публично можно только читать витрину и создавать заявку. Изменять данные и видеть список броней (с телефонами) может только админ.
- Занятость отдаёт публичный `/api/neo/busy` — только интервалы времени, без данных клиентов.
- Сервер сам задаёт статус «Новая», берёт цены и допуслуги из базы, проверяет часы, число гостей, пересечения и «не в прошлом».
- Саморегистрация в `users` отключена.

## Деплой

- `dockerfile.backend` — PocketBase. **Подключите постоянный том к `/app/pb_data`**, иначе база и фото пропадут при перезапуске.
- Сайт: `npm run build`, затем `npm start` или любой статический хостинг (все пути должны отдавать `index.html`).
- ИИ-помощник: ключ только на сервере PocketBase (`AI_API_KEY`, `AI_API_BASE`, `AI_MODEL`); без ключа отвечает из встроенной базы знаний. Тексты помощника — в `src/components/AiAssistant.tsx`.

## Про демо-фото

В `public/images` лежат нарисованные заглушки (логотип, главное фото, галерея). Загрузите настоящие фото в админке: «Логотип», «Главное фото», «Работы».

## Не вошло в архив

`pocketbase.exe`, `pocketbase_bin` и `pb.zip` (бинарники и, возможно, копия данных) — скачайте PocketBase с официального сайта и не публикуйте `pb.zip`.
